TwoFly stamp art
================
Save finished 600x800 PNG files here. Filename = id, not a number.

stamps/landmarks/<id>.png
stamps/states/<id>.png          (two-letter, e.g. NM.png)
stamps/countries/<id>.png       (ISO-2, e.g. US.png)

Workflow: free-use photo or flag → oil paint → red overlay on top → export PNG.
Drop the file in the matching folder. No code change. Unlock the stamp in the app, then open it.
